
# Expense Tracker

A command-line app to record and summarise daily expenses using SQLite.

## Features
- Add, view and delete expenses
- Category-wise totals and overall total
- Data saved permanently in `expenses.db`

## Technologies
Python, SQLite3

## How to Run
```bash
python main.py
```

## Menu
| Option | Action |
|---|---|
| 1 | Add expense |
| 2 | View all expenses |
| 3 | Summary by category |
| 4 | Delete by ID |
| 5 | Exit |

## Future Improvements
- Input validation
- Filter by date or month
- Export to CSV
